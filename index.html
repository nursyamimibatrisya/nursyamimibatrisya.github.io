Professional Profile

Saya Nur Syamimi Batrisya, pelajar tahun 1 program Bachelor of Computer Science (Data Engineering) di Universiti Teknologi Malaysia (UTM). Saya komited untuk mendalami kemahiran teknikal dalam pengurusan ekosistem data yang berskala besar.

Kemahiran & Alatan: HTML, CSS, Figma, GitHub, dan konsep asas Sistem Pangkalan Data.

Learning Journey

Melalui kursus SCST1133, saya belajar mengaplikasikan systems thinking untuk memahami bagaimana infrastruktur IT menyokong sistem berasaskan data. Pemahaman saya berkembang daripada konsep asas pengiraan (Foundations) kepada landskap industri (Landscape) dan kepentingan tadbir urus etika (Responsibility) dalam menguruskan kitaran hayat data (Data Lifecycle).

Selected Work & Artifacts

1. Design Thinking and Figma Project (CLO3)

Contribution & Purpose: Membina prototaip aplikasi interaktif berasaskan rangka kerja Design Thinking untuk menyelesaikan masalah pengurusan data pengguna secara efektif.

Reflection: Tugasan ini mengajar saya cara memetakan keperluan pengguna ke dalam struktur data yang sistematik. Cabaran utama adalah mengimbangi reka bentuk UI yang mesra pengguna dengan etika privasi data. Penambahbaikan masa depan adalah memperkemas simulasi aliran data dalam prototaip.

2. Industry Talk & Visit Insights (CLO1)

Contribution & Purpose: Menganalisis perkongsian pakar industri mengenai trend teknologi terkini dan peranan real-world seorang Data Engineer.

Reflection: Aktiviti ini mendedahkan saya kepada aplikasi praktikal big data dan sistem teragih. Saya memahami kepentingan kolaborasi antara peranan (Data Analyst & Scientist). Sesi ini memotivasikan saya untuk mempelajari teknologi cloud computing sebagai langkah persediaan kerjaya.

3. Data Engineering Lifecycle Video (CLO2)

Contribution & Purpose: Menghasilkan video penerangan kumpulan yang membentangkan setiap fasa kitaran hayat data daripada proses data acquisition sehinggalah storage.

Reflection: Proses ini memperjelas pemahaman saya tentang bagaimana data ditransformasikan sebelum sedia dianalisis. Cabaran utama adalah menerangkan peringkat data validation secara ringkas. Saya akan menambah contoh semakan kualiti data (data quality check) jika video ini disemak semula.

Course Learning Summary

Kursus SCST1133 telah mengubah perspektif saya terhadap pengurusan maklumat. Saya kini sedar bahawa kejayaan sesuatu sistem AI atau analitik bergantung sepenuhnya kepada keutuhan ekosistem data di belakangnya. Saya berhasrat untuk mendalami bahasa Python dan SQL bagi mengukuhkan kemahiran data engineering saya.
