Learning Journey

In SCST1133, I learned how IT infrastructure and data work together using systems thinking. The course helped me connect everything—starting from basic computing foundations, understanding the modern data landscape, seeing how the industry works, and realizing why data ethics and responsibility matter so much.

Selected Work & Artifacts

1. Design Thinking and Figma Project (CLO3)

Contribution & Purpose: I worked with my team to design an interactive app prototype in Figma. We followed the Design Thinking framework to make sure the app actually solves a real problem for users.

Reflection: This project taught me how to translate what a user needs into a clean, working system layout. The hardest part was making the app easy to use while keeping user data private and safe (ethics). Next time, I want to make the data flow in the prototype more interactive.

2. Industry Talk & Visit Insights (CLO1)

Contribution & Purpose: I listened to tech experts talk about real-world big data and what a Data Engineer actually does every day.

Reflection: Hearing from professionals made me realize how huge big data really is. I learned how closely Data Engineers, Analysts, and Scientists have to collaborate. It motivated me to start looking into cloud computing early so I can prepare for my future career.

3. Data Engineering Lifecycle Video (CLO2)

Contribution & Purpose: My group created an explanatory video to break down the main stages of the data engineering lifecycle, focusing on data acquisition and storage.

Reflection: Making this video helped me clearly see how raw data changes before it is ready for analysis. It was challenging to explain the validation part simply. If I could redo it, I would add a better example showing how a data quality check fixes bad data before the next step.

Course Learning Summary

SCST1133 completely changed how I look at technology. I used to think coding was everything, but now I know that any good AI or application is only as good as the data ecosystem supporting it. Moving forward, I want to focus heavily on learning Python and SQL to strengthen my core skills.
